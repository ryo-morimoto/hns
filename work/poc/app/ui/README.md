# Agentic Workspace UI PoC

作業用の試作。製品コードではない（`packages/web` は 0036 で作る）。

**Intent は [INTENT.md](INTENT.md)（不変条件）。Golden Examples のフローは [GOLDEN.md](GOLDEN.md)（参考）。**
フローと Intent が衝突したら Intent を取り、逸脱を INTENT に記録する。
会話を主画面にするのではなく、**エージェントに委任した仕事を一覧し、人間の判断が必要なものから開く**。
ここでは Linear / Cursor / Manus / Claude Cowork / Replit の Agentic Workspace と、
Rauno / Linear / Stripe の Interaction Craft から借りた判断を、実際に触れる形で確かめる。

## 借りた原則

| 原則 | この PoC での具体化 |
| --- | --- |
| Task over Chat | 既定は「ワークスペース」。実行中 / あなたの判断 / 完了の3つが主で、会話は詳細 |
| Delegation with Ownership | 「仕事を頼む」でゴールを渡す。仕事のカードには「エージェント実行中」「あなたの判断」を明示 |
| Observability without Noise | 進捗は「考え中 / ツール実行中 / 待ち」の短い語。ツール出力は折りたたみ |
| Review over Replay | 完了カードは結果の要約と「結果」ボタン。実行詳細はノード単位で確認 |
| Direct Manipulation | 会話を離れず右パネルでファイルを編集し、差分と競合をその場で処理 |
| Async by Default | 実行中でも別の仕事へ。タブに (N)、離席中に応答が来たら ●。戻れば続きから |
| Visual Craft | 低コントラストのサイドバー、11–24px の階層、4px の余白、境界線は必要な1本だけ |
| Interaction Craft | hover / focus / selected / disabled の4状態、150ms の遷移、コマンドパレット、インライン改名 |
| State Design | loading skeleton、空、エラー＋再試行、オフライン、中断、Undo、未完の仕事 |
| Coherence | 同じトークン・menu / dialog / toast / badge を全画面で使う |

## 画面

```
┌ topbar: hns / project ▾ ───── 現在地 ───── 接続 · ⌘K · テーマ · ? ┐
├ sidebar 264px ─┬ workspace home ────────────────────┬ editor (on demand) ┤
│ ワークスペース  │ project / 仕事を頼む                │ path · version     │
│ 新しい会話      │ Running · Needs you · Completed     │ files | textarea   │
│ 検索 /          │ あなたの判断が必要（入力待ち）       │ diff / conflict    │
│ 会話一覧        │ バックグラウンドで実行中             │                    │
│ タスク          │ 完了した仕事                        │                    │
│ 実行（runs）    └─────────────────────────────────────┴────────────────────┘
└ status: 最終更新 ── ⌘K · ? ── tokens · provider · sandbox ┘
```

### ワークスペース（既定）

- 3つの数字が最初に目に入る: **実行中 / あなたの判断 / 完了**。
- 「あなたの判断が必要」は full width。入力待ちの Workflow、停止・中断・未完の会話、停止したタスクを並べる。
- 「バックグラウンドで実行中」は run のノード進捗と、応答中の会話。
- 「完了した仕事」は run の結果要約と、完了したタスク・会話。空のセクションは出さない。
- 「仕事を頼む」でゴールを渡すと、会話を作って送信し、その会話へ移る。完了を待たずに戻れる。

### 会話（詳細）

- 左一覧から開く。送信中・実行中は composer の上に「作業中 / 待ち」を出し、**停止**を常に同じ位置に置く。
- 進捗は Durable の task を人間語に直す（`pi.generation` → 考え中、`pi.tool` → ツール実行中）。
- 中断されたツールは「中断されました」と表示し、会話はワークスペースの「あなたの判断」に戻る。
- ツール結果は折りたたみ。コードブロックはコピーできる。
- 応答が来たときに下まで読んでいれば追従し、読んでいる途中なら「最新へ」を出す（勝手に飛ばさない）。

### エディタ（右パネル）

- 会話の文脈を壊さないよう、既定は閉じる。開閉は `⌘E` / ヘッダーのボタン / URL。
- dirty・保存・再読込・差分・競合（再読込 / 上書き）は 0008/0009 の状態機械をそのまま使う。
- ファイル切替・パネルを閉じる・ホームへ戻る前に、dirty なら確認する。確認したらメモリ上の編集は破棄する。

## 状態

| 状態 | 表示 |
| --- | --- |
| 初回読み込み | ブランド + シマーの boot、home は skeleton |
| 空 | 「まだ仕事はありません」+ 仕事を頼む / 新しい会話 |
| エラー | 赤いバナー + 再試行。429 は待ち時間、423 はロックとして区別 |
| オフライン | 上部バナー + status の赤ドット。SSE が切れても polling で継続し「ポーリング」と出す |
| 実行中 | 進捗バー + 経過時間 + 停止。実行中はタブタイトルに (N)、離席中に応答が来たら ● |
| 入力待ち | Workflow run が「あなたの判断」に出る。モーダルで出力を返すと再開 |
| 中断・未完 | 会話カードに「中断」「未完」。開いて続きを送るか「確認済み」でキューから外す（local） |
| 競合 | エディタ上部に「外部で変更されました」+ 再読込 / 上書き。差分で確認できる |
| 破壊的操作 | 削除は確認、アーカイブとタスク状態は Undo 付き toast |

## キーボード

| キー | 動作 |
| --- | --- |
| `⌘K` / `Ctrl+K` | コマンドパレット |
| `H` | ワークスペースへ |
| `N` | 新しい会話 |
| `J` / `K` | 仕事カードを移動 |
| `Enter`（カード） | カードの主要アクション |
| `Enter`（入力中） | 送信（IME 変換中は除く） |
| `/` | 会話検索へフォーカス |
| `Shift+Enter` | 改行 |
| `⌘E` / `Ctrl+E` | エディタ開閉 |
| `⌘S` / `Ctrl+S` | 保存 |
| `?` | ショートカット一覧 |
| `Esc` | メニュー / パレット / ダイアログを閉じる |

## URL

- `#/p/<projectId>` — ワークスペース
- `#/p/<projectId>/c/<conversationId>` — 会話
- `#/p/<projectId>/c/<conversationId>/editor[/<path>]` — 会話 + エディタ

ブラウザの戻る/進むでワークスペース ↔ 会話 ↔ エディタが戻る。
プロジェクトと会話は URL が真。テーマと最後に開いたファイルだけ localStorage。

## この増分でやらないこと

- Workflow の作成・グラフ編集（0038）。run の閲覧、waiting への応答、実行開始は API で確認。
- Automation の作成・編集。
- 設定の永続化（provider / 秘密 / 制限）。接続情報の閲覧だけ。
- React / Vite 化。製品 UI は 0036 で `packages/web` に作る。
- Markdown の完全なレンダリング。フェンスコード・インラインコード・URL だけ。

## 次に試すこと

1. 仕事（task / run / conversation）を同じ ID で束ねる。いまは種類ごとのカード。
2. Ack をサーバーに永続化する。いまは localStorage で、updated_at が変われば再表示される。
3. Cursor の Review のように、完了カードから差分・テスト結果・プレビューへ直行する。
4. Undo の対象を広げる（アーカイブ、タスク状態は実装済み）。
5. 実 Provider での長いストリームと、切断→再接続の体感。
6. モバイルの「今すぐ判断」導線（いまは home をスクロール）。
