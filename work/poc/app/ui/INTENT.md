# Intent — invariant

date: 2026-11-07 · scope: `work/poc/app/ui`（製品 UI は 0036）

このファイルは **変えない前提**。Golden Examples のフロー（[GOLDEN.md](GOLDEN.md)）は参考であり、
フローと意図が衝突したら **意図を取り、逸脱を記録する**。

## 一文

**運用者が、エージェントに任せた仕事のうち「人間の判断が要るもの」だけを開き、その場で決め、
成果物は同じ画面で直せる。会話は詳細であり、主画面ではない。**

## 誰の、何のため

- 利用者: 自分のマシンで複数の Agent を動かす 1 人の運用者。
- 仕事: 任せる → 待つ → 判断する → 成果物を見る/直す。
- いまの痛み: 会話ログを追い、どこで止まったか探し、別画面でファイルを直し、下書きを失う。

## 成功条件（検証できる形）

1. ホームを開いて **3秒以内** に「いま自分が判断すべきもの」が分かる。
2. 判断待ちは **ホームを離れず** に入力・状態変更・確認済みにできる。 inspection が要るときだけ開く。
3. 実行中でも別の仕事を開き、戻れる。待ちを理由に操作をブロックしない。
4. 下書き・エディタの未保存・会話の文脈を **黙って失わない**。
5. 何も無いとき、次にできることが **1つ** 見える。
6. 実行中はタブ・ホーム・会話のどこにいても分かる。

## やらないこと（Non-goals）

- チャット中心の UI。会話は詳細。
- Agent の思考ログを眺める監視ダッシュボード。
- 無限キャンバス / 3D / WebGL / カスタムカーソル。
- マルチユーザー、権限管理、請求。
- Workflow の作成・グラフ編集（0038）。Automation の作成。
- 分析のための分析（グラフ、集計のための集計）。

## 不変条件（Invariants）

| # | 条件 | 破れたら |
| --- | --- | --- |
| I1 | 既定はワークスペース。会話は詳細 | ホームに戻る導線（H / パンくず）を壊さない |
| I2 | Needs you が最初の走査。全幅で、実行中より上 | 完了や統計を先に置かない |
| I3 | 判断はインライン。開くのは inspection のときだけ | モーダル/画面遷移を増やさない |
| I4 | バックグラウンドが見える（タイトル (N)、実行中カード、停止） | 「待つ」を理由に操作を止めない |

| I7 | 1サーフェス1主アクション（home=仕事を頼む、会話=送信、editor=保存） | 主アクションを増やさない |
| I8 | Keyboard parity（H/N/J/K/Enter/⌘K/⌘E/⌘S/?） | マウス専用の主要操作を作らない |

## 逸脱チェック（Drift checks）

新しい画面・部品を入れる前に、5つだけ問う。

1. これは「判断までの時間」を短くするか。
2. Intent に無い概念を増やしていないか（例: 新しいステータス、別の仕事モデル）。
3. 参照元の **表面** をコピーしていないか。判断をコピーしているか。
4. これを消したら、どの Invariant が壊れるか。
5. empty / waiting / error / interrupted のどれを担当するか。

フローの手順が意図に合わないなら、**手順を飛ばして理由を書く**。
「Canary flow の通りにやった」は成果ではない。

## 現在のドリフト（既知）

- task / run / conversation に共通の WorkItem ID が無い。カードは種類ごと。
- Ack は localStorage のみ。サーバーの判断状態ではない。
- 会話ごとのスクロール位置は保持しない（下書き・エディタの dirty は保持する）。
- Run 詳細はモーダルで、URL / 戻るの対象ではない（inspection としては動く）。
- モバイルで Needs you への固定ジャンプが無い。
- 実 Provider の長いストリーム、切断→再接続の実測が無い。

## 変更のルール

- この Intent を変えるのは利用者だけ。変更は日付・理由・影響する Invariant をここに追記する。
- 実装が Intent に追いつかないときは、コードより先に「現在のドリフト」へ書く。
- フロー（GOLDEN.md）は更新してよい。Intent は勝手に更新しない。
