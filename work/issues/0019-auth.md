# 0019: 認証と公開範囲（要件13）

status: done
depends-on: 0014
touches: work/poc/app

## Goal

localhost 前提をやめ、入口を token で閉じる。外に出しても最低限の境界がある状態にする。

## Acceptance criteria

- [x] token なしの API は 401
- [x] Bearer / query / cookie のどれでも通る
- [x] Webhook は自分の token で動く（アプリ token 不要）
- [x] token は再起動しても変わらない
- [x] 既定は loopback にだけ bind

## Result

- token は `HNS_TOKEN`、なければ state ディレクトリの `token`（0600）に生成。
- `startApp({ auth })` で切り替え（テスト用）。UI は `?token=` を受けて `sessionStorage` に保持し、以後の fetch / SSE に付ける。
- 残り: 複数ユーザー / RBAC、TLS、失敗回数の制限。
