# セキュリティの観点

パス・コマンド・秘密・sandbox・認可・既定値・降格に触る変更で読む。根拠は [design.md](../design.md)。

| 観点               | 条件                                                                                      | 確認                                                                                                                | Ref                                                                                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 入力が外へ出る     | 外部の文字列がパス・temp 名・コマンド・URL の一部になる                                   | `../`・`:`・NUL・超長を1つ通す。内部生成に置き換えられないか                                                        | [Parse, Don't Validate](https://lexi-lambda.github.io/blog/2019/11/05/parse-don-t-validate/), [OWASP API Security](https://owasp.org/API-Security/)                                                        |
| 秘密が外へ出る     | token・key・body・header がログ・イベント・例外・fixture・repo に入る                     | 実ログと例外を検索し、残るのがパスと状態だけか。env 除去・hide・fail closed も確かめる（[safety.md](../safety.md)） | [OWASP API Security](https://owasp.org/API-Security/), [PAGNI (security)](https://jacobian.org/2021/jul/8/appsec-pagnis/)                                                                                  |
| 認可の境界         | 利用者・スコープ・project を跨ぐ。id をクライアントが送る                                 | セッション必須ルートを認証無しで呼ぶ。別スコープの secret。判定がサーバ側か                                         | [Fail Fast](https://martinfowler.com/ieeeSoftware/failFast.pdf), [OWASP API Security](https://owasp.org/API-Security/)                                                                                     |
| 静かな降格         | fallback・helper の失敗で弱い経路に落ちる                                                 | `mode`・health・ログに出るか。docs の意図した降格は合格、黙って落ちるのは欠陥                                       | [Fail Fast](https://martinfowler.com/ieeeSoftware/failFast.pdf)                                                                                                                                            |
| 既定が安全側でない | 安全側が既定値・オプション・起動時の1箇所に依存する（env 継承、hide、rooted、許可ルート） | 既定のまま危険な値を通す。呼び出し元があるか。無いなら配線するか docs に不活性と書く                                | [Fail Fast](https://martinfowler.com/ieeeSoftware/failFast.pdf), [API Design](https://www.infoq.com/articles/API-Design-Joshua-Bloch/), [PAGNI (security)](https://jacobian.org/2021/jul/8/appsec-pagnis/) |
