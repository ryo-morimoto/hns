# 観点の評価

観点を足す・削る前に読む。既知の欠陥と安全な反例で、規律が効いているかを確かめる（指摘の数では測らない）。
見るのは、検出（既知の欠陥を拾う）、誤検知（安全な反例を FAIL にしない）、修正可能性（指摘に修正案が付く）。

| 変更                                                    | 期待する振る舞い                  |
| ------------------------------------------------------- | --------------------------------- |
| 後方互換を黙って壊した（移行も decisions の記録も無い） | blocking で指摘する               |
| 宣言して移行する、または decisions に破壊的変更を書いた | 指摘しない                        |
| 今回の変更と無関係な既存の穴                            | blocking にしない（issue にする） |
| テストは緑だが境界値で壊れる                            | 再現して指摘する                  |
| 冗長だが正しく動く                                      | 全面改修を求めない                |
| 環境が無く確認できない                                  | BLOCKED か未確認と明記する        |
